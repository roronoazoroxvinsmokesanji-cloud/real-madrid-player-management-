
# ⚽ Real Madrid Player Management

A beginner Python project that models football players and team captains using object-oriented programming.

## Features

- Create football player objects and store their statistics
- Calculate goals per match
- Validate goals, matches played, and jersey numbers
- Use encapsulation with private attributes and properties
- Demonstrate inheritance, method overriding, and `super()`
- Change the default team using a class method
- Validate jersey numbers using a static method

## Concepts Practised

- Classes and objects
- Constructors (`__init__`)
- Encapsulation and properties
- Inheritance and method overriding
- Class methods and static methods
- Input validation and exceptions
- Functions and the main guard

## Requirements

- Python 3.10 or newer
- No external libraries required

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run the following command in the terminal:

```bash
python main.py
```
